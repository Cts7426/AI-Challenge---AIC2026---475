# Thiết kế

Thư mục này lưu tài liệu thiết kế cho thay đổi kiến trúc hoặc subsystem mới.
Mỗi tài liệu phải nêu mục tiêu, phạm vi, ranh giới module, dữ liệu/hợp đồng,
failure mode và chiến lược kiểm chứng.

Không sao chép luật thi, bất biến hoặc báo cáo đo vào đây: dùng liên kết tới
`AGENTS.md`, `docs/contest.md`, `ARCHITECTURE.md` và `reports/` làm nguồn thật.
Thiết kế được duyệt phải có kế hoạch triển khai tương ứng trong `docs/plans/`.
