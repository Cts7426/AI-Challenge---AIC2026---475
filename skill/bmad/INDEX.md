# 📚 Trạm Điều Phối BMAD (AI Challenge AIC2026)

Chào mừng bạn đến với trung tâm điều phối của dự án AIC2026. Tất cả các Agent khi tham gia vào dự án phải đọc file này và bám sát các Epics đang được triển khai.

## 🎯 Mục Tiêu Phase Hiện Tại
Dự án đã vượt qua giai đoạn xây dựng hệ thống cốt lõi. Giai đoạn hiện tại là **Khai Thông Pipeline & Tuning**:
- Tích hợp các cụm Search, Slot Allocator, và QA/TRAKE pipeline vào chung một API duy nhất.
- Bổ sung dữ liệu cho `dev_set/` để chạy `app/eval.py`.
- Tối ưu hóa các hệ số thông qua Mô phỏng điểm D3.5.
