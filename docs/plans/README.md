# Kế hoạch thực thi

Thư mục này lưu kế hoạch triển khai theo từng thay đổi có thể kiểm chứng. Mỗi
kế hoạch ghi rõ file bị tác động, test/lệnh đo, acceptance criteria và artefact
cần lưu. Ưu tiên task nhỏ, chạy được và truy nguyên được.

`BUILD_TASKS.md` vẫn là lộ trình và trạng thái vận hành liên đợt; không di chuyển
lịch sử task hoặc bằng chứng hoàn thành khỏi file đó. Kế hoạch mới phải liên kết
đến design tương ứng trong `docs/design/` và task liên quan trong `BUILD_TASKS.md`.
